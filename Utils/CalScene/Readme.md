# CalScene #

The role of the CalScene application is to convert the [config](https://github.com/wildboar-dev/GLOC/blob/main/Data/DSet_000/Config/2025-09-03%2015%3A38%3A05.xml) into tangible outputs:

* A meta file for representing the calibration parameters and distortion for the scene.
* A image file for visualizing how the output looks.
* A points file for getting the exact point positions for processing.
